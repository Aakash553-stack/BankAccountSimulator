# Bank Account Simulator

A command-line Java application that simulates real banking operations.
Built to demonstrate core Object-Oriented Programming principles in Java.

## Features
- Create a bank account with your name and starting balance
- Deposit money with input validation
- Withdraw money with overdraft protection
- View formatted account balance and summary
- Interactive menu-driven interface

## What I Learned
- Object-Oriented Programming (classes, objects, constructors)
- Encapsulation using private fields and public methods
- Input validation and error handling
- Java Scanner for user input
- NumberFormat for currency formatting

## How to Run
1. Clone the repository
2. Open in IntelliJ IDEA
3. Run Main.java

## Technologies
- Java 21
- IntelliJ IDEA
